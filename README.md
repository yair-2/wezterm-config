# 介绍

WezTeram 的 Windows 版本的 DIY 配置文件，将 `.wezterm.lua` 文件放在用户根目录下即可生效。

将终端分为三部分，左边、右上、右下。一份为二，左边占 50%，右上和右下平分右边 50%；效果如下：

# 快捷键

## 标签页管理

| 新建标签页            |     Ctrl+Shift+T     |
| :-------------------- | :------------------: |
| 新建窗口              |     Ctrl+Shift+N     |
| 关闭当前标签页        |     Ctrl+Shift+W     |
| 切换第 1 ~ 9 个标签页 |    Ctrl+Shift+1~9    |
| 上一个/下一个标签页   | Ctrl+PgUp/Ctrl+PgDn  |
| 标签页左移/右移       | Ctrl+Shift+PgUp/PgDn |
